# @ng-agentic/core

## 0.2.1

### Patch Changes

- Design fix: the summary card now renders on the base content surface like every other component, instead of a fully coloured AI-tinted background that drowned the information and could read as an alert. AI provenance stays where it belongs — in the small accents: the "Generated by AI" label and the gradient bar. Restore the old look with `definePreset(Base, { components: { summary: { background: '{ai.subtleBackground}', borderColor: '{ai.borderColor}' } } })`.

## 0.2.0

### Minor Changes

- **Localizable labels** — every user-facing string in the components (plan statuses, "Thinking…", tool-call badges, approval buttons, "Generated by AI", suggestion hints, code-block copy…) now flows through the `AgtLabels` system: `provideAgentic({ labels })` accepts a static object or a Signal for live language switching. Defaults are unchanged.

  **Theming** — the sidebar FAB shadow now derives from `ai.color` (was hardcoded violet), the `toolCall.*` and `summary.*` component tokens defined in presets are actually wired into the styles, and a new `components.codeBlock` token set makes the syntax-highlighting palette fully themeable.

  **ESM** — `@ng-agentic/themes` is now published as a proper ES module with an `exports` field (fixes the "not ESM" optimization warning in Angular CLI consumers).
